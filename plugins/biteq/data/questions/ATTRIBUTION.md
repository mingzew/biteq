# Third-party questions

The loader only reads `*.json`; this file is not a bank.

## lydiahallie/javascript-questions

`js.json` questions with ids `js-lydia-<n>` come from
https://github.com/lydiahallie/javascript-questions (commit a8b427b9f7f9), question `<n>` there.
Each has `"source": "lydiahallie/javascript-questions #<n>"`.

Changes from the original: Markdown and HTML removed (the pane shows plain text), image references
and pointers to other questions dropped, and questions with 2, 3 or 5 options brought to 4. #14
(do all objects have prototypes) was rewritten because the original explanation was incorrect.
#72 got a new explanation and #82 says it runs in a browser.
